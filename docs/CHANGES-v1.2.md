### 1.2. §3.4 — определить триггер fallback (сейчас он не определён)

Добавить после абзаца про модели:

> **Триггер fallback `medium → large-v3`:** повтор выполняется один раз на клип, если после первой попытки выполнено хотя бы одно условие:
> - транскрипт пуст или содержит < 5 слов;
> - доля сегментов с `avg_logprob < -1.0` превышает 30 %;
> - доля сегментов с `no_speech_prob > 0.6` превышает 30 %;
> - итоговая длительность распознанной речи < 30 % длительности аудио.
>
> Если fallback тоже не дал результата — клип переходит в `failed` с текстом причины. Больше одной попытки fallback не делается.

### 1.3. §3.5 — добавить абзац про неподдерживаемые глифы

> Символы, отсутствующие в выбранном шрифте (эмодзи, редкие глифы, латиница в нестандартной гарнитуре), вырезаются на этапе генерации `.ass`, чтобы libass не подставлял чужой шрифт и не ломал метрики строки.

### 1.4. §3.6 — fps и контроль размера

Добавить в раздел:

> **Частота кадров:** по умолчанию `fps: auto` — берётся из исходника, но не выше 60. При исходнике 60 fps допускается даунсемпл до 30 (экономия времени рендера), решение фиксируется в конфиге, а не в коде.
>
> **Контроль размера:** после рендера проверяется размер файла. Если он > 45 МБ, выполняется до 2 повторных кодирований с шагом `crf += 4` (20 → 24 → 28) на уже готовом файле, без повторной сборки фильтр-графа. Если и после этого файл > 45 МБ — админу уходит файл как документ + предупреждение, модерация №2 продолжается по ссылке на локальный файл.

### 1.5. §3.7 — ограничения на правку текста при переделке

Добавить в описание кнопки «На переделку»:

> Правка текста субтитров принимается сообщением до 1000 символов; переносы строк и разбивка по словам пересчитываются автоматически по сохранённым таймкодам. Если новый текст не выравнивается по числу слов с исходным транскриптом, правка отклоняется с понятным сообщением админу (таймкоды не «досочиняются»).

### 1.6. §3.8 — схема `meta.json` и ретеншн

Заменить абзац про `meta.json` на:

> `meta.json` (UTF-8, `schema_version: 1`):
>
> ```json
> {
>   "schema_version": 1,
>   "clip_id": "SomeClipSlug",
>   "clip_url": "https://clips.twitch.tv/SomeClipSlug",
>   "channel": { "login": "streamer", "display_name": "Streamer", "url": "https://twitch.tv/streamer" },
>   "category": { "id": "29595", "name": "Dota 2" },
>   "clip": { "title": "...", "duration_sec": 42.3, "views": 12345, "created_at": "2026-11-20T18:03:00Z" },
>   "render": {
>     "version": 1, "width": 1080, "height": 1920, "fps": 30, "duration_sec": 42.2,
>     "video_codec": "h264", "audio_codec": "aac", "size_bytes": 21400000,
>     "crf": 20, "subtitles_mode": "karaoke", "hook_text": null, "subtitle_language": "ru"
>   },
>   "source": { "transcribe_provider": "faster-whisper", "model": "medium" },
>   "published_at": "2026-11-25T21:14:00Z",
>   "status": "published"
> }
> ```
>
> Поля `render.version` и `published_at` обязательны; при повторной публикации версии ключ объекта не меняется, а `meta.json` перезаписывается с новым `version`.
>
> **Ретеншн:** мастера в R2 хранятся `publish.retention_days` (по умолчанию 180) и удаляются lifecycle-правилом бакета. Правило настраивается один раз вручную, код его не создаёт.

### 1.7. §3.9 — TTL карточек модерации

Добавить:

> Кандидат, отправленный на модерацию №1, «протухает» через `parser.candidate_ttl_hours` (по умолчанию 24 ч): если админ не нажал ни одну кнопку, клип переходит в `rejected` с причиной `expired`, карточка в TG редактируется (кнопки убираются, добавляется пометка «просрочено»). Просроченные клипы не блокируют очередь и не считаются в ежедневной сводке как отказы админа.

## 4. Новые ADR для `docs/DECISIONS.md`

Добавить записи в том же формате:

- **D-012 · Лимит размера файла под Telegram Bot API.** 45 МБ как предохранитель, ступенчатый `crf`, fallback на отправку документом. Причина: Bot API отдаёт файлы до 50 МБ, высокодетальный 60-секундный кадр может не влезть.
- **D-013 · fps наследуется от исходника.** `auto`, не выше 60; 30 — осознанный выбор для экономии рендера, а не дефолт «на всякий случай».
- **D-014 · TTL карточек модерации.** 24 ч, авто-`rejected` с причиной `expired`; причина — иначе очередь и чат забиваются старыми карточками.
- **D-015 · Ретеншн мастеров 180 дней.** Lifecycle-правило бакета, настраивается вручную; код ретеншном не управляет.
- **D-016 · Fallback Whisper по качеству, а не по времени.** Триггеры из §3.4 v1.2; fallback не более одного раза на клип.
